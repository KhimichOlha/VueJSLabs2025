# Лабораторна робота №5: Використання PrimeVue та створення плагінів

## Тема проєкту

BugTracker Pro — лендінг SaaS-продукту для відстеження помилок у програмному забезпеченні. Проєкт реалізовано на Vue 3 з використанням бібліотеки компонентів PrimeVue.

---

##  Кроки запуску проєкту

1. Відкрийте термінал у папці проєкту (lab5).
2. Встановіть необхідні залежності:
   ```bash
   npm install
   ```
3. Запустіть проєкт у режимі розробки:
   ```bash
   npm run dev
   ```
   Відкрийте посилання, яке з'явиться у терміналі (зазвичай http://localhost:5173/).

##  Структура лендінгу

Лендінг складається з наступних логічних секцій:

- **Header**: Навігаційне меню з логотипом та кнопками входу.
- **Hero-секція**: Головний екран із заголовком, закликом до дії та демонстрацією першого використання плагіна (копіювання промокоду).
- **Проблема – Рішення**: Блок, що описує болі клієнта та як продукт їх вирішує (реалізовано в компоненті Features.vue).
- **Переваги**: Сітка з основними фічами продукту (реалізовано в компоненті Features.vue).
- **Як це працює**: Покрокова інструкція інтеграції через Timeline (реалізовано в компоненті HowItWorks.vue).
- **Тарифи / Плани**:
  - 3 картки тарифів (Starter, Team, Enterprise).
  - Інтерактивний калькулятор: дозволяє ввести кількість користувачів та автоматично розраховує місячний бюджет.
- **Відгуки**: Карусель (Carousel) з відгуками клієнтів (реалізовано в компоненті SocialProof.vue).
- **FAQ**: Секція з частими запитаннями у вигляді акордеону (реалізовано в компоненті SocialProof.vue).
- **Контактна форма**: Форма для заявки з валідацією полів та маскою для телефону.
- **Footer**: Підвал сайту з копірайтом та соцмережами.

У проєкті використано наступні компоненти з бібліотеки PrimeVue:

| Компонент          | Опис використання                                                                 |
|--------------------|-----------------------------------------------------------------------------------|
| **Menubar**       | Головне меню навігації (MyHeader.vue).                                            |

| **Carousel**      | Слайдер відгуків клієнтів (SocialProof.vue).                                      |
| **Accordion / AccordionPanel** | Блок поширених запитань FAQ (SocialProof.vue).                                    |

| **Textarea**      | Поле для повідомлення (ContactForm.vue).                                          |

##  Налаштування PrimeVue

Підключення бібліотеки виконано у файлі main.js:

- Імпортовано PrimeVue та тему Aura (@primeuix/themes/aura).
- Імпортовано базові стилі іконок: primeicons/primeicons.css.
- Бібліотеку підключено через `app.use(PrimeVue, { theme: { preset: Aura } })`.
- Додатково підключено сервіс ToastService для роботи спливаючих повідомлень.

##  Опис плагіна CopyToClipboardPlugin

Власний плагін реалізовано у файлі src/plugins/copyToClipboard.js.

- **Логіка роботи**: Плагін додає глобальну функцію `copyToClipboard`, яка використовує `navigator.clipboard` для копіювання тексту. Повертає `true` у разі успіху.
- **Підключення**: Зареєстровано в main.js через `app.use(CopyToClipboardPlugin)`. Доступ у компонентах забезпечується через `inject('copyToClipboard')`.
