# Лабораторна робота №3: Стилізація компонентів у Vue.js

Цей проект є виконанням лабораторної роботи №3 в рамках курсу Vue.js. Метою роботи було закріплення навичок стилізації компонентів (Scoped Styles, CSS Modules), роботи з Vue Router, налаштування анімацій переходів та використання компонента <Teleport>.

##  Функціональні можливості

Проект реалізує міні-сайт новин із таким функціоналом:

* Маршрутизація (Vue Router):
    * Головна сторінка (Список новин).
    * Сторінка новини (Динамічний маршрут /article/:id).
    * Інформаційна сторінка "Про нас".
    * Обробка 404 помилки.
* Стилізація:
    * Використання <style scoped> для ізоляції стилів компонентів.
    * Використання CSS Modules для стилізації карток новин (NewsCard.module.css).
    * Динамічна темізація (CSS змінні).
* UI/UX:
    * Перемикач теми (Light/Dark) зі збереженням стану в localStorage.
    * Модальне вікно з рекламою, реалізоване через <Teleport to="body">.
    * Анімації: Плавні переходи між сторінками (<Transition> для RouterView) та анімація появи модального вікна.
    * Скрол вгору при переході між сторінками.

##  Інструкція запуску

Для запуску проекту локально виконайте наступні кроки:

1.  Встановлення залежностей:
        npm install
    

2.  Запуск у режимі розробки:
        npm run dev
    

3.  Збірка для продакшену:
        npm run build
    

##  Структура проекту

* src/components/ — Перевикористовувані компоненти (Header, Footer, NewsCard, ModalWindow, AdSlot).
* src/views/ — Сторінки додатка (Home, Article, About, NotFound).
* src/router/ — Налаштування маршрутизації.
* src/data/ — Мок-дані (новини).
* src/assets/ — Глобальні стилі.

##  Висновок: Особливості стилізації у Vue.js

У ході виконання лабораторної роботи було досліджено різні підходи до стилізації у Vue 3:

1.  Scoped Styles (`<style scoped>`): Це найзручніший механізм для повсякденної розробки. Vue автоматично додає унікальні атрибути (data-v-...) до елементів, що гарантує, що стилі не "витечуть" в інші компоненти. Це вирішує проблему конфлікту імен класів у великих проектах.
    
2.  CSS Modules: Забезпечують ще суворішу ізоляцію, генеруючи унікальні імена класів (хеші). Це корисно для бібліотек компонентів або критичних елементів інтерфейсу, де важливо уникнути будь-якого впливу глобальних стилів. У Vue вони інтегруються нативно через атрибут module.

3.  Динамічні стилі та Теми: Використання CSS Custom Properties (змінних) у поєднанні з реактивністю Vue дозволяє легко реалізувати перемикання тем (Dark/Light mode) без необхідності дублювати CSS код.

4.  Teleport та Transition: Vue надає вбудовані компоненти для вирішення складних UI-задач, таких як рендеринг модальних вікон поза DOM-деревом батьківського компонента (Teleport) та декларативний опис анімацій появи/зникнення елементів (Transition), що значно спрощує створення інтерактивних інтерфейсів.
